# Finanças pessoais (Vida Tranquila, nome provisório)

App web instalável (PWA) para registar receitas, despesas, dívidas, metas e impostos de trabalhador independente.

- **Só código neste repositório.** Os dados ficam encriptados (AES-GCM) apenas no telemóvel de quem usa a app.
- Funciona sem internet depois de instalada.
- Instalar no iPhone: abrir o endereço no Safari → Partilhar → "Adicionar ao ecrã principal".
